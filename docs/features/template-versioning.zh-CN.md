# 模板版本历史

SublinkPro 会为每个模板保留内容历史。每次保存都会生成一个不可变的新版本，任意两个版本都可以对比，任意版本都可以下载或恢复。

---

## ✨ 功能概览

| 能力 | 行为 |
|:---|:---|
| **自动快照** | 新建模板或保存编辑器内容时自动生成新版本 |
| **版本数量不限** | 没有保留上限，直到模板被删除为止 |
| **并排对比** | 支持两个历史版本互相对比，也支持历史版本与当前内容对比 |
| **下载** | 任意版本都可以下载为普通模板文件（`<名称>.v<版本号><扩展名>`） |
| **恢复** | 可将任意版本恢复为当前内容。恢复采用追加方式：写入旧内容后再生成一个 `restore` 版本，历史不会丢失 |
| **仅恢复内容** | 恢复只修改模板内容，分类、规则源、代理等元数据保持不变 |
| **随模板删除** | 删除模板时会同时删除模板文件、元数据和全部版本历史 |

---

## 🧭 工作原理

### 版本来源

| 来源 | 生成时机 |
|:---|:---|
| `baseline` | 启用版本功能后，已有模板首次保存时记录保存前磁盘上的原始内容 |
| `add` | 新建模板 |
| `save` | 保存内容且文件名未变化 |
| `rename` | 保存内容并重命名文件 |
| `restore` | 恢复历史版本 |

### 快照存放位置

模板内容仍然保存在 `template/<名称>`，快照保存在同级目录：

```text
template/
├── clash.yaml
└── .versions/
    └── <模板ID>/
        ├── 000001.snapshot
        ├── 000002.snapshot
        └── ...
```

数据库中只保存版本元信息（版本号、内容摘要、大小、来源、操作人、时间）。系统备份压缩包本来就包含 `template/` 目录，因此快照会自动包含在备份中。

### 重复保存

如果保存的内容与最新版本完全一致，不会生成新版本，避免无意义的重复记录。

## 🖥️ 界面操作

1. 打开 **模板管理**。
2. 点击模板行上的 **版本历史** 图标。
3. 弹窗按时间倒序列出全部版本，显示大小、操作人、来源，并用 **当前版本** 标记与磁盘内容一致的版本。
4. 行内操作：
   - **预览**：在只读编辑器中查看该版本内容。
   - **下载**：下载版本文件。
   - **恢复**：恢复该版本（需要二次确认）。
5. 选择一个版本点击 **与当前内容对比**，或选择两个版本点击 **对比所选版本**，打开带增删统计的并排对比视图。

## 📡 API 概览

所有接口都需要认证，路径前缀为 `/api/v1/template`。

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| `GET` | `/versions?filename=&page=&pageSize=` | 版本列表（倒序），元素包含 `isCurrent` |
| `GET` | `/versions/:version?filename=` | 版本元信息与 `content` |
| `GET` | `/versions/:version/download?filename=` | 下载版本快照文件 |
| `GET` | `/versions/diff?filename=&from=&to=` | 统一 diff 与两侧内容，`to=0` 表示与当前模板文件对比 |
| `POST` | `/versions/restore` | 表单：`filename`、`version`，可选 `comment` |

`POST /template/add` 与 `POST /template/update` 支持可选的 `comment` 表单字段，会随新版本一起保存。

---

## 📝 说明

- 版本历史按模板维度保存，重命名不会丢失历史，因为版本以模板 ID 关联。
- 通过界面之外的方式（例如直接复制文件到 `template/`）新增的模板，会在下一次保存时生成首个历史版本。
- 快照只保存模板内容，不会把代理链接等凭据复制进版本记录。
